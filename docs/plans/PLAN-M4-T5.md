# M4 T5 구현 계획 — `gslack tui` 미리보기 포커스

> 2026-10-15 · 대상: TASKS M4 T5(새 항목), PRD-TUI.md §3 · 상태: Codex·Opus 리뷰 반영(Fable은 한도로 Opus가 대신)
> 목표(사용자 요청): Enter로 아래(미리보기)에 포커스가 간 것이 보이고, 아래에서 메시지를 골라 스크롤하며, 고른 메시지가 보인다. 위(목록)의 빈 공간을 줄인다.
> 사용자 결정(2026-10-15): **r·o는 고른 메시지로**(j/k 이동, Esc로 목록) · **목록 높이는 포커스 따라**(목록 포커스면 줄 수에 맞춰 최대 40%, 미리보기 포커스면 작게).
> PRD-TUI §3 "레이아웃 하나, 미리보기는 Enter로"는 그대로 — 포커스 둘이 생길 뿐 화면 구성은 같다.

## 1. 포커스

- `m.focus bool`(true = 미리보기). 목록에서 `Enter` → 미리보기 받기 + `focus = true`. `Esc` → `focus = false`.
- 미리보기 포커스의 키: `j/k`·`↑/↓` 메시지 이동, `pgup/pgdown/space` 화면 스크롤(지금 viewport KeyMap), `r`·`o` 고른 메시지로, `m`·`R`·`q`는 목록과 같다(지금 줄 기준).
- 표시: 미리보기 위 구분선에 제목 — 목록 포커스면 지금처럼 `────`, 미리보기 포커스면 `━━ #general ━━━`(굵게). 목록 커서 줄은 포커스가 없으면 Reverse 대신 밑줄. 상태줄 키 힌트도 바뀐다(`j/k 메시지  r 답장  o 브라우저  Esc 목록  m 치우기  q 끝`).
- 답장 입력 중 키는 지금처럼 가장 먼저(입력이 끝나면 포커스는 그대로).

## 2. 미리보기 메시지 고르기

- `previewMsg`를 받으면 메시지(`[]core.Message`)와 각 메시지의 시작 줄을 모델에 둔다: `m.pvMsgs`, `m.pvStarts`, `m.pvLines`(렌더링한 줄), `m.sel`.
- **시작 줄**: `printMessages`가 메시지마다 시작 줄 번호를 돌려주게 한다(`[]int`, 날짜 머리줄 다음 줄). `read`는 무시. T4의 "안 본 부분을 따로 찍어 날짜 줄이 경계"는 없앤다 — 고른 메시지 강조가 경계 표시를 대신한다.
- **처음 고른 메시지**: 안 본 첫 메시지(T4의 `last_read`), 모르면 마지막. 안 본 첫 메시지면 그것을 맨 위에(T4 그대로), 아니면 맨 아래.
- **강조**: 고른 메시지의 줄들(`pvStarts[sel]`부터 다음 메시지 시작 전까지, 날짜 머리줄 제외)에 Reverse. 고를 때마다 `pvLines`를 복사해 그 범위만 스타일을 입혀 `SetContent`. 렌더링(`s.render`)은 previewMsg 때 한 번.
- **보이게**: 고른 메시지의 시작이 화면 위보다 위면 그 줄을 맨 위로, 끝이 화면 아래보다 아래면 끝을 맨 아래로(메시지가 화면보다 길면 시작을 맨 위로).
- `pgup/pgdown`으로 화면만 스크롤하면 선택은 그대로(다음 `j/k`가 다시 보이게 한다).
- 메시지가 없거나 미리보기 실패면 `j/k`는 아무것도 안 하고 `r`·`o`는 줄 기준(지금 그대로).

## 3. r·o는 고른 메시지로

- `o`: 고른 메시지의 `Permalink`.
- `r`: **history 미리보기**면 줄의 복사본에 `latest = 고른 메시지`를 넣어 지금 `replyThread` 규칙 그대로 — DM·그룹 DM 본문이면 대화에 바로, 채널이면 그 메시지에 스레드로, broadcast 같은 스레드 답글이면 그 스레드. **스레드 미리보기**면 고른 메시지와 상관없이 그 스레드(지금 줄 그대로 — 부모를 골라도 DM 본문으로 새지 않게).
- 답장 뒤 읽음은 지금 `send` 규칙 그대로(채널 줄이면 답한 메시지 ts까지 mark — 옛 메시지에 답하면 그 뒤는 안 읽음으로 남는다. 다 치우려면 `m`).
- 입력줄 머리 `답장 #general ↳ @minsu: 첫 줄…`(고른 메시지 미리보기 30자)로 대상을 보여 준다.

## 4. 목록 높이

- `m.height`(WindowSizeMsg)를 두고 `layout()`이 `listH`·`vp.Height`를 정한다: 목록 포커스면 `min(목록 줄 수, height*2/5)`, 미리보기 포커스면 `min(목록 줄 수, 3)`. 목록 줄 수 = 머리줄 + 줄(빈 목록이면 1). 최소 1.
- `Update`는 끝에서 늘 `layout()`(줄 수·포커스·크기가 바뀌는 곳이 많아서 한 곳에서). `vp.Height`가 바뀌면 고른 메시지를 다시 보이게.
- View는 지금처럼 `listH`줄 + 구분선 + 미리보기 + 구분선 + 상태줄 = 화면 높이.

## 5. 리뷰 반영(Codex·Opus)

- **미리보기한 줄을 따로 둔다 — `m.pvRow`**: `preview(r)`가 `previewMsg`에 줄을 싣고, 받으면 `m.pvRow`. 미리보기 포커스의 `r`·`o`·`m`은 `m.rows[m.cur]`가 아니라 `pvRow` 기준(실시간·채우기가 목록을 바꿔 커서가 다른 줄로 가도 엉뚱한 채널로 안 보내게). 답장 뒤·"불확실" 뒤 다시 미리보기도 `pvRow`(고른 메시지를 넣은 복사본이 broadcast면 스레드 미리보기로 바뀌던 것).
- **Enter 때 이전 미리보기를 비운다**: `pvMsgs = nil`, `sel = 0`, 내용 `head + "불러오는 중…"`. 비어 있는 동안 `j/k`는 무시, `r`·`o`는 `pvRow` 줄 기준. 실패해도 비운 채.
- **키 순서**: 답장 입력 → 미리보기 포커스(`esc` 목록, `j/k/↑/↓` 고르기, `enter` 무시, `r`·`o`·`m` pvRow) → 공통(`q`·`R`) → 목록. `pgup/pgdown/space`는 지금처럼 viewport.
- **`m` 성공이면 포커스를 목록으로** — 치운 뒤 다음 줄로 가기 쉽게.
- **줄 번호**: `printMessages`는 자기가 쓴 줄 기준 0부터 메시지 첫 줄 번호를 돌려준다. 미리보기 내용에선 head 한 줄을 더한다. 맨 위로 맞출 때 바로 앞 줄이 날짜 머리줄이면 그 줄부터.
- **layout 한 곳**: 본문을 `update()`로 옮기고 `Update`는 `update` 뒤 늘 `layout()`(이른 return이 많다). 목록 줄은 View와 같은 `listLines()`로 센다(머리줄 둘, 빈 문구). 높이가 바뀌면 `SetYOffset(YOffset)`로 clamp 후 고른 메시지를 다시 보이게.
- **강조는 Reverse**: 미리보기 줄은 평문이라(`render`는 ANSI를 안 넣는다) Reverse를 덧입혀도 깨지지 않고, viewport는 줄바꿈 없이 자른다(줄 번호 = 화면 행).
- DM에서 스레드 부모를 골라 `r`이면 대화 본문으로(기존 `replyThread` 규칙, 입력줄에 `↳` 없음으로 구분).

## 테스트

- `TestTUIFocus`: Enter → focus, 구분선에 대화 이름, 힌트 바뀜. Esc → 목록. 미리보기 포커스에서 j/k가 목록 커서를 안 바꿈.
- `TestTUIPreviewSelect`(previewMsg 직접, 30개): 처음 고른 것 = 안 본 첫 메시지(맨 위), `j` 끝까지 → 고른 메시지가 화면 안, 강조 줄이 그 메시지. `k`로 처음 위로. last_read 모르면 마지막을 고르고 맨 아래.
- `TestTUIPreviewReply`: 채널 history에서 옛 메시지 골라 `r` → `thread_ts` = 그 ts, mark = 그 ts. DM → thread 없음. 스레드 미리보기에서 부모 골라 `r` → 그 스레드. `o` → 고른 메시지 permalink.
- `TestTUILayout`: 줄 2개 → listH 3(머리줄 포함), 미리보기 포커스 → ≤3, 화면 줄 수 = 높이.
- 리뷰 반영: 미리보기 포커스 중 목록이 바뀌어도(`liveMsg`로 새 줄이 위에) `r`이 pvRow 채널로. Enter 직후(응답 전) `r` → 줄 기준. 미리보기 포커스에서 Enter → seq 그대로. `m` 성공 → 목록 포커스. broadcast 골라 답장 뒤 미리보기가 history 그대로. 높이 바뀜(WindowSizeMsg) 뒤 고른 메시지가 화면 안.
- 기존 `TestTUIPreviewFirstUnread`는 경계 날짜 줄 단언을 강조로 바꾼다. `read` 출력 테스트 그대로.

## 안 하는 것

- 20개 넘는 안 읽음 더 받기.
